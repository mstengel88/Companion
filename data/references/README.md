# Emily reference images

Place the two canonical images here, or upload them from Settings in the app.

Recommended names:

- `emily-reference-1.jpg` (or `.png`/`.webp`)
- `emily-reference-2.jpg` (or `.png`/`.webp`)

The application records hashes and dimensions in local state and passes the filenames into a configured generic ComfyUI workflow. Images stay local and are excluded from Git by default.

The images attached in the referenced ChatGPT conversation were not included in the exported conversation payload available to this build, so the package intentionally contains empty slots rather than substituted images.
